# Лабораторная работа 3

Вариант 40.

## Задание

Реализовать функцию `moveZerosToEnd(items)`, которая перемещает все нулевые
элементы массива в конец, сохраняя относительный порядок остальных элементов.

## Реализация

Функция `moveZerosToEnd` находится в `solution.js` и экспортируется как
именованный ESM-экспорт. Алгоритм проходит по массиву один раз: ненулевые
элементы собираются в отдельный массив с сохранением порядка, а количество
встреченных нулей подсчитывается отдельно. Результат — конкатенация массива
ненулевых элементов и такого же числа нулей в конце. Сложность — O(n) по времени
и O(n) по памяти, исходный массив не изменяется.

## Запуск

```bash
node --input-type=module -e "
import { moveZerosToEnd } from './solution.js';
console.log(moveZerosToEnd([0, 1, 0, 3, 12]));
"
```
