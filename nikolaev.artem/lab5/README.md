# Лабораторная работа 5

## Задание

Вариант 40.

Реализовать компонент "Избранное" для книжного интернет-магазина. Список книг
содержит обложку, название, рейтинг, описание и цену. У каждой книги — кнопка
"Добавить в избранное", по нажатию на которую книга появляется в отдельном
компоненте "Избранное" с возможностью удаления и счётчиком добавленных книг.
Состояние избранного сохраняется в localStorage.

## Реализация

`App` хранит массив `favoriteIds` и синхронизирует его с localStorage через
`useEffect`. `BookCard` отображает книгу и кнопку `favorite-add`, переключающую
книгу в списке избранного. `FavoritesPanel` показывает добавленные книги
(`favorite-item`) с кнопкой удаления и текстом-заглушкой для пустого списка.
Счётчик избранного выводится в кнопке `favorites-count` в шапке и одновременно
открывает/закрывает панель.

## Запуск

Выполнить `npm install`, затем `npm run dev`
