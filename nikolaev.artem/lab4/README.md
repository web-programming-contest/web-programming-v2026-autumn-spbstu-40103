# Лабораторная работа 4

## Задание

Вариант 40, задача 4. Класс `Travel` (`id`, `travelerName`, `visitedCountries`,
методы `addCountry`/`removeCountry`, геттер `visitedCount`) и пять функций для
группировки и поиска по массиву путешествий. UI: карточки путешествий,
асинхронные (Promise + setTimeout) добавление/удаление путешествий и стран,
автообновление интерфейса и сохранение состояния в localStorage.

## Реализация

- `model.js` — класс `Travel` и пять функций п. 4.2.
- `main.js` — форма создания путешествия (`entity-form`), список
  (`entity-list`), карточки (`entity-card`) с добавлением/удалением стран и
  удалением путешествия (`delete-entity`). Дубликаты id и стран блокируются с
  уведомлением. Все изменения — асинхронно, с сохранением в localStorage.
- `index.html` / `styles.css` — разметка и стили.

## Запуск

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000/` ссылку в браузере.
