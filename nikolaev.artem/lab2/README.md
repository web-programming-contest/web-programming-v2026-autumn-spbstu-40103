# Лабораторная работа 2

## Задание

Вариант 40.

Написать функцию timeAgo(date, now), возвращающую строку с описанием того,
сколько времени прошло с переданной даты (например, "5 минут назад", "2 часа
назад", "3 дня назад").

## Реализация

Считаем разницу между now и date в секундах, находим подходящую единицу времени
(минуты, часы, дни) по таблице UNITS и делим разницу на её divisor. Склонение
слова подбирается функцией pluralize по остатку от деления числа на 10 и 100.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
