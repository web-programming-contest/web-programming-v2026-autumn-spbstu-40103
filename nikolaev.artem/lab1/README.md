# Лабораторная работа 1

## Задание

Вариант 40.

Сверстать флаг Бангладеша, сам красный круг в центре сделать с помощью position:
absolute, разместив его точно по центру (чтобы он оставался по центру даже если
увеличить размеры флага). Сами размеры флага - на ваше усмотрение.

## Реализация

Добавлен блок `.flag` с зелёным фоном и `position: relative`, задающий систему
координат для дочернего элемента. Внутри — блок `.circle`, позиционированный
через
`position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%)`, что
центрирует круг независимо от размеров флага. Размер круга задан в процентах
(`width: 40%`) вместе с `aspect-ratio: 1 / 1`, поэтому при изменении размеров
флага круг масштабируется пропорционально, оставаясь идеально круглым.

## Запуск

Откройте `index.html` в браузере.
