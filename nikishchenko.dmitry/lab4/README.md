# Лабораторная работа 4

## Задание

Вариант 39.

4.1. Создать класс course с полями:

- courseId — уникальный номер (число)
- title — название курса (строка)
- students — массив объектов студентов, каждый с id и name

Реализовать методы:

- addStudent(student) — добавить студента
- removeStudent(studentId) — удалить студента по id
- геттер studentCount — количество студентов

4.2. Дан массив курсов:

- Группировать курсы по количеству студентов
- Получить уникальный список всех студентов
- Вернуть курсы, в которых учится заданный студент по id
- Группировать студентов по курсам
- Получить курсы с максимальным количеством студентов

4.3. Реализовать пользовательский интерфейс:

- Список с карточками курсов: название, список студентов, количество студентов
- Кнопки: "Добавить студента", “Удалить студента”, “Добавить курс”, "Удалить
  курс"
- Форма создания курса (ID, название). Форма добавления студентов
- При любых изменениях автоматически обновлять пользовательский интерфейс
- Все операции добавления/удаления выполнять асинхронно через Promise +
  setTimeout()
- Использовать local storage для сохранения текущего списка студентов при
  закрытии вкладки.

## Реализация

Модель и функции работы с коллекцией находятся в `model.js`, логика интерфейса —
в `main.js`.

**Модель.** Класс `Course` хранит `courseId`, `title` и массив `students`.

- `addStudent(student)` — проверяет, что имя не пустое и студента с таким ID ещё
  нет на курсе, затем добавляет его; иначе бросает ошибку
- `removeStudent(studentId)` — удаляет студента по ID; если его нет на курсе,
  бросает ошибку
- `studentCount` — геттер, возвращает длину массива `students`

**Функции работы с коллекцией.**

- `groupCoursesByStudentCount(courses)` — объект «количество студентов →
  названия курсов»
- `getUniqueStudents(courses)` — массив уникальных студентов (по ID) по всем
  курсам
- `findCoursesByStudent(courses, studentId)` — курсы, на которые записан студент
- `groupStudentsByCourse(courses)` — объект «название курса → список студентов»
- `findLargestCourses(courses)` — курсы с наибольшим количеством
  студентов
- `createSampleCourses()` — начальные данные (3 курса)

**Интерфейс.**

- `render()` и `createCard()` — перерисовывают карточки курсов, список курсов в
  форме студента и сводку (количество курсов и уникальных студентов)
- `asyncOperation(action)` — выполняет действие через `Promise` + `setTimeout`
  (500 мс)
- `perform(action, successText)` — запускает асинхронную операцию, затем
  сохраняет данные, перерисовывает интерфейс и показывает уведомление; ошибки
  показываются в уведомлении
- `loadCourses()` и `saveCourses()` — чтение и запись списка курсов в
  `localStorage` (ключ `courses`); сохранение выполняется при закрытии вкладки
  (`beforeunload`) и после каждой операции
- Формы проверяют ID (положительное целое число), названия и имена; ID студента
  не может принадлежать двум разным людям

## Запуск

Компиляция не нужна, проект написан на чистом JavaScript (ES-модули).

Запустите локальный сервер в папке проекта:

```
python3 -m http.server 8000
```

Откройте `http://localhost:8000` в браузере.

Открытие `index.html` двойным щелчком (`file://`) не сработает: браузер
блокирует загрузку модулей. Вместо команды выше можно использовать расширение
Live Server в VS Code.
