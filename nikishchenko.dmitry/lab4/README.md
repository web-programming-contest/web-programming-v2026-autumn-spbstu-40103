# Лабораторная работа 4

## Задание

39 вариант.

Небольшое веб-приложение для учёта курсов и записанных на них студентов. Написано на чистом HTML, CSS и JavaScript (ES-модули), без сборщиков и внешних библиотек.

## Возможности

- Добавление и удаление курсов (уникальные ID и названия).
- Добавление студентов на курс и удаление их с курса.
- Один и тот же студент (по ID) может быть записан на несколько курсов; ID не может принадлежать двум разным людям.
- Сводка в шапке: количество курсов и уникальных студентов.
- Валидация данных с понятными сообщениями об ошибках (всплывающие уведомления).
- Имитация асинхронных операций (задержка 500 мс) с уведомлением «Сохраняем…».
- Анимации появления карточек и учёт `prefers-reduced-motion`.
- Адаптивная вёрстка (одна колонка на экранах до 900 px).

## Запуск

Приложение использует ES-модули, поэтому **файл `index.html` нельзя открывать двойным щелчком** (адрес `file://`): браузер заблокирует загрузку `main.js`, и страница будет пустой. Нужно открыть проект через локальный сервер.

Вариант 1 — VS Code:

1. Установите расширение **Live Server**.
2. Щёлкните правой кнопкой по `index.html` → **Open with Live Server**.

Вариант 2 — Python (в папке проекта):

```bash
python3 -m http.server 8000
```

После этого откройте в браузере <http://localhost:8000>.

## Как это работает

### `course.js`

Класс `Course`:

| Член                  | Описание                                                                         |
| --------------------- | -------------------------------------------------------------------------------- |
| `constructor(courseId, title, students = [])` | Создаёт курс.                                            |
| `addStudent(student)` | Добавляет студента `{id, name}`. Бросает ошибку при пустом имени или дубликате ID. |
| `removeStudent(id)`   | Удаляет студента. Бросает ошибку, если его нет на курсе.                         |
| `studentCount`        | Геттер — количество студентов на курсе.                                          |

Вспомогательные функции:

| Функция                                  | Результат                                              |
| ---------------------------------------- | ------------------------------------------------------ |
| `groupCoursesByStudentCount(courses)`    | Объект «число студентов → названия курсов».            |
| `getUniqueStudents(courses)`             | Массив уникальных студентов по всем курсам.            |
| `getCoursesByStudentId(courses, id)`     | Курсы, на которые записан студент с данным ID.         |
| `groupStudentsByCourse(courses)`         | Объект «название курса → список студентов».            |
| `getCoursesWithMaxStudents(courses)`     | Курсы с наибольшим числом студентов.                   |
| `createSampleCourses()`                  | Начальные демонстрационные данные (3 курса).           |

### `main.js`

- `loadCourses()` / `saveCourses()` — чтение и запись данных в `localStorage` (ключ `courses`).
- `asyncOperation()` и `perform()` — обёртка над действием с задержкой, сохранением, перерисовкой и уведомлением об успехе или ошибке.
- `render()` и `createCard()` — построение карточек курсов, списка студентов и выпадающего списка курсов в форме.
- `showMessage()` — всплывающее уведомление (`role="status"`, `aria-live="polite"`).
- Результаты функций из `course.js` дополнительно выводятся в консоль браузера (`console.warn`).

## Примечание

В начале `main.js` есть строка `localStorage.removeItem('courses');`. Она очищает сохранённые данные при каждой загрузке страницы, поэтому изменения не сохраняются между перезагрузками. Если нужно, чтобы данные сохранялись, удалите эту строку.
