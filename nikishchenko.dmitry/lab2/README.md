# Лабораторная работа 2

## Задание

Вариант 39.

Написать функцию, которая преобразует цвет из HEX-формата в RGB-формат
(например, "#FF0000" -> "rgb(255, 0, 0)").

## Реализация

Функция hexToRgb сначала проверяет корректность вводимого значения (в начале
должна стоять решетка (#), значение должно состоять из букв и цифр,
последовательность должна быть длиной равной 6). После этого мы по двум разрядам
(начиная от старшего до младшего) переводим значение из 16-ричной системы в
десятичную. Возвращаем строчку `rgb(${r}, ${g}, ${b})`.

## Запуск

Проверить можно в браузере, открыв Консоль РАзработчика (F12) и вставив код
функции.
