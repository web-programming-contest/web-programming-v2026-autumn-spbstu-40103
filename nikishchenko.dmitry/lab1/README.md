# Лабораторная работа 1

## Задание

39 вариант.

Создать форму регистрации как на изображении ниже. Форма должна
удовлетворять следующим требованиям:
- Ширина формы – 400px;
- Внутренний отступ – 8px;
- Цвет кнопки - #0056ff;
- Цвет кнопки при наведении курсора - #417ffb.

## Реализация

Построил форму через html + css + js. html - каркас, css - подключаемые стили,

в js делается проверка на валидность номера телефона и почты, совпадение паролей,

а также сохранение пользователей (чтобы нельзя было создавать несколько пользователей 

с идентичными почтами и телефонами) в localStorage.

## Запуск

Откройте `index.html` в браузере и попробуйте отправить форму.
