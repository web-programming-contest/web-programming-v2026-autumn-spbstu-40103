# Лабораторная работа 3

## Задание

Вариант 39.

Написать функцию convertBase(num, fromBase, toBase), преобразующую число между
Реализуйте функцию countOccurrences(arr), которая возвращает объект с
количеством вхождений каждого элемента.

## Реализация

Создается пустой объект (Object), который служит словарем (как в Питончике
любимом). И далее в цикле добавляем элементы: если при обращении по ключу item
получаем undefined, то наш ИЛИ с 0 вернет 0. Если все ок - вернется счетчик
объекта до этого. В любов случае, прибавляем единичку и записываем новое
значение счетчика для item в наш словарь.

## Запуск

Откройте в браузере Консоль Разработчика (F12) и запустите код в ней.
