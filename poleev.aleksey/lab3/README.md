# Лабораторная работа 3

## Задание

Вариант 17. Максимумы скользящих окон. Реализовать функцию
`maxSlidingWindow(arr, k)`, которая находит максимумы во всех подмассивах длины
`k`.

## Реализация

Функция экспортируется из `solution.js` как именованный ES module export и
возвращает новый массив максимумов каждого окна слева направо. Входной массив не
изменяется.

Алгоритм использует монотонный убывающий дек индексов. Перед добавлением нового
индекса из хвоста дека удаляются все индексы со значениями меньше или равными
новому, поэтому дек всегда упорядочен по убыванию значений. Индекс в начале дека
уходит, как только выходит за границы окна. Для удаления без сдвига элементов
применяется указатель `head`.

Максимум окна — значение по индексу из начала дека, он записывается в результат
начиная с позиции `k - 1`. Каждый индекс добавляется и удаляется из дека не
более одного раза, поэтому сложность O(n) при памяти O(k), вместо наивных
O(n·k).

Граничные случаи: пустой массив, `k` меньше единицы, нецелое `k` и `k` больше
длины массива возвращают пустой массив. Отрицательные числа и повторяющиеся
максимумы обрабатываются корректно.

## Запуск

Импортируйте `maxSlidingWindow` из `solution.js` как ES module:

```js
import {maxSlidingWindow} from './solution.js';

maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3);
```
