# Лабораторная работа 1

Вариант 17.

## Задание

Создать веб-страницу с тремя колонками, которые адаптируются к размеру экрана:
на больших экранах колонки располагаются рядом в один ряд, на средних — в два
столбца, на маленьких — одна под другой.

## Реализация

Страница свёрстана на HTML5 и CSS Grid без использования сторонних библиотек.
Подключаемый файл `styles.css` не содержит inline-стилей и `!important`.

Разметка: `index.html` содержит заголовок `h1` и элемент
`<main class="columns">`, внутри которого находятся три блока `.column`.
Раскладка построена по принципу desktop-first: базовый стиль —
`grid-template-columns: repeat(3, 1fr)` (три колонки).

Адаптивность задана двумя медиа-запросами:

- `@media (width < 900px)` — `grid-template-columns: repeat(2, 1fr)`, две
  колонки в ряд, третья растягивается на всю ширину через `grid-column: 1 / -1`.
- `@media (width < 600px)` — `grid-template-columns: 1fr`, одна колонка,
  растяжение третьей колонки сбрасывается.

Горизонтальный overflow отсутствует: `box-sizing: border-box`, ширина контейнера
ограничена `max-width: 1400px` и отцентрована через `margin: 0 auto`. Размер
заголовка задаётся через `clamp()`.

## Запуск

Открыть `index.html` в браузере двойным кликом либо через локальный сервер. Для
проверки адаптивности изменить ширину окна браузера: до 600px — одна колонка,
600–900px — две колонки, более 900px — три колонки.
