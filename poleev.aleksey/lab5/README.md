# Лабораторная работа 5

## Задание

Вариант 17 — «Канбан-доска» (kanban). Интерактивная доска в стиле Trello для
управления задачами.

Требования:

- создание, редактирование и удаление карточек;
- организация карточек в колонки («Сделать», «В процессе», «Готово»);
- перетаскивание карточек между колонками (drag-and-drop);
- сохранение состояния доски в `localStorage`.

Публичный DOM-контракт для проверки:

- `[data-testid="kanban-column"]` — колонки (не менее двух);
- `[data-testid="kanban-card"]` — карточка;
- `[data-testid="kanban-add"]` — кнопка добавления карточки;
- `[data-testid="kanban-done"]` — зона-приёмник колонки «Готово».

## Реализация

React-приложение на Vite. Drag-and-drop реализован на нативных HTML5-событиях
(`draggable`, `dragstart`, `dragover`, `drop`) без внешних библиотек, чтобы
решение собиралось доверенным toolchain и не требовало интернета.

### Данные (`src/boardData.js`)

Состояние доски — плоская структура: `cards` (словарь карточек по id) и
`columns` (массив колонок со списком `cardIds`). Модуль экспортирует чистые
функции без мутации входа: `createInitialState`, `loadBoard`, `saveBoard`,
`addCard`, `removeCard`, `updateCardText`, `moveCard`, а также константу
`DONE_COLUMN_ID`. `loadBoard` читает `localStorage` с фолбэком на дефолтную
доску; `saveBoard` пишется в `useEffect` при каждом изменении состояния.

### Компоненты (`src/components/`)

- `Board.jsx` — хранит состояние, синхронизирует с `localStorage`, обрабатывает
  `dragstart`/`drop` и делегирует действия в чистые функции.
- `Column.jsx` — рендерит колонку `kanban-column` и drop-зону; для колонки
  «Готово» зона получает `data-testid="kanban-done"`. Подсвечивает цель при
  перетаскивании.
- `Card.jsx` — перетаскиваемая карточка `kanban-card` с inline-режимом
  редактирования и кнопками «Изменить»/«Удалить».
- `AddCardForm.jsx` — форма создания карточки: поле текста, выбор колонки и
  кнопка `data-testid="kanban-add"`.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной. Для сборки
— `npm run build`.
