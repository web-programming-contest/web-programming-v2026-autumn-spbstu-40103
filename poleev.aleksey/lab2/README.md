# Лабораторная работа 2

## Задание

Вариант 17. Аббревиатура. Написать функцию, которая преобразует строку в
аббревиатуру (например, "JavaScript Object Notation" → "JSON").

## Реализация

Функция `toAbbreviation` находит в строке все слова регулярным выражением
`/[A-Z]?[a-z]+|[A-Z]+(?![a-z])/g`, берёт первую букву каждого слова, переводит
её в верхний регистр и склеивает результат.

Границы слов учитываются не только по пробелам, но и по camelCase, поэтому
"JavaScript Object Notation" распадается на Java, Script, Object, Notation и
даёт "JSON", а "cascading style sheets" — на "CSS".

Граничные случаи: пустая строка и строка без букв возвращают пустую строку,
лишние пробелы игнорируются, одиночное слово даёт одну букву.

## Запуск

Импортируйте `toAbbreviation` из `solution.js` как ES module.
