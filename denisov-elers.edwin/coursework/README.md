# Курсовая работа

## Задание

Спроектировать, реализовать и продемонстрировать проект интернет-магазина гаджетов Gadget Hub.

## Реализация

Фронтенд реализован на React + TypeScript + Vite. Бэкенд - ExpressJS. Даннные хранятся в JSON файлах.

## Запуск

Выполните `npm install`, затем `npm run dev`.
