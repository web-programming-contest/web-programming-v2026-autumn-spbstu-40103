# Лабораторная работа 5

## Задание

Вариант 4.

Задача 5. Реализовать механику рейтинга в книжном интернетмагазине Создать
список книг, который будет содержать обложку книги, название, рейтинг, описание
и цену. В каждом компоненте книги добавить возможность выставлять рейтинг книги
пользователем. Рейтинг рассчитывается по средней оценке (сумма оценок деленное
на их количество). Функционал компонента рейтинга:

- принимает количество звезд (по умолчанию 5);
- принимает рейтинг (число);
- возможность изменить рейтинг пользователем (после голосования, на 3- 4 с.
  после оценки отображается выбранный пользователем, затем возвращается в
  среднее состояние).

## Реализация

Есть 2 компонента - Rating для механики рейтинга и BookCard для карточки книги.
При изменении рейтинга вызывается onRate, изменяющий количество голосов и
суммарный рейтинг в массиве Book[], содержащем информацию о книгах. Через 3
секунды после выбора рейтинга он скрывается и показывается средний.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
