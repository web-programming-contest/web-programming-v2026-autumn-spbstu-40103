# Лабораторная работа 2

## Задание

Вариант 32.

Задача 2. Написать функцию `findLongestPalindrome(str)`, которая находит и
возвращает самую длинную подстроку-палиндром в переданной строке.

## Реализация

В файле `solution.js` экспортируется функция `findLongestPalindrome`.

Решение проходит по строке и для каждого символа пробует построить палиндром от
центра. Отдельно проверяются палиндромы нечетной длины, например `level`, и
четной длины, например `abba`. Если найденный палиндром длиннее текущего ответа,
он становится новым ответом.

Если строка пустая, функция возвращает пустую строку.

## Запуск

Импортируйте функцию из `solution.js` как ES module:

```js
import {findLongestPalindrome} from './solution.js';
```
