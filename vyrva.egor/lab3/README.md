# Лабораторная работа 3

## Задание

Вариант 32.

Задача 3. Реализовать функцию `difference(arr1, arr2)`, которая возвращает
массив элементов, которых нет во втором массиве.

## Реализация

В файле `solution.js` экспортируется функция `difference`.

Сначала значения второго массива добавляются в `Set`, чтобы быстро проверять,
есть ли элемент во втором массиве. Потом первый массив фильтруется: в новый
массив попадают только те элементы, которых нет в `arr2`.

Метод `filter` возвращает новый массив, поэтому `arr1` и `arr2` не изменяются.

## Запуск

Импортируйте функцию из `solution.js` как ES module:

```js
import {difference} from './solution.js';
```
