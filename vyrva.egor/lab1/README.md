# Лабораторная работа 1

## Задание

Вариант 32.

Задание: Сверстать флаг Японии, сам красный круг в центре сделать с помощью
position: absolute, разместив его точно по центру (чтобы он оставался по
центру даже если увеличить размеры флага). Сами размеры флага - на ваше усмотрение.

## Реализация

В `index.html` находится простая страница с заголовком, описанием задания и
блоком флага. Белая часть флага сделана элементом `div` с классом `flag`, а
красный круг внутри него сделан элементом `div` с классом `circle`.

У блока `flag` стоит `position: relative`, чтобы круг позиционировался
относительно флага. У круга стоит `position: absolute`, `top: 50%`, `left: 50%`
и `transform: translate(-50%, -50%)`, поэтому он находится ровно в центре.

## Запуск

Откройте `index.html` в браузере.
