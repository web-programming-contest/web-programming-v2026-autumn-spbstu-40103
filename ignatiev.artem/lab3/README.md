# Лабораторная работа 3

## Задание

Реализовать функцию maxSlidingWindow(arr, k), которая находит максимумы во всех
подмассивах длины k. Например, maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3)
возвращает [3, 3, 5, 5, 6, 7].

## Реализация

Решение находится в solution.js, функция maxSlidingWindow экспортируется по
имени. Используется очередь индексов, в которой значения идут по убыванию,
поэтому максимум текущего окна всегда стоит в начале очереди. Индексы вышедших
из окна элементов удаляются, а меньшие элементы вытесняются с конца. Сложность
O(n). Если k не положительное или больше длины массива, возвращается пустой
массив. Входной массив не изменяется.

## Запуск

Импортировать функцию: import {maxSlidingWindow} from './solution.js'; и
вызвать, например, maxSlidingWindow([1, 3, -1, -3, 5, 3, 6, 7], 3).
