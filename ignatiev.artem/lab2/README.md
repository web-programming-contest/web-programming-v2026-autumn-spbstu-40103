# Лабораторная работа 2

## Задание

Реализовать функцию zipArrays(...arrays), которая объединяет массивы поэлементно. Например, zipArrays([1, 2], ['a', 'b']) возвращает [[1, 'a'], [2, 'b']].

## Реализация

Решение находится в solution.js, функция zipArrays экспортируется по имени.
Длина результата равна длине самого короткого массива. Для каждого индекса
собирается подмассив из элементов всех переданных массивов. Если массивы не
переданы, возвращается пустой массив. Входные массивы не изменяются.

## Запуск

Импортировать функцию: import {zipArrays} from './solution.js'; и вызвать,
например, zipArrays([1, 2], ['a', 'b']).
