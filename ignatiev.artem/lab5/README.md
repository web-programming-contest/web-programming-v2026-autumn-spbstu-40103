# Лабораторная работа 5

## Задание

Вариант 24, задача «Корзина покупок». Нужно сделать список книг в магазине, у
каждой книги — кнопка добавления в корзину. Под списком через горизонтальную
линию выводится корзина.

Функциональность: кнопка добавляет книгу в корзину, если её там ещё нет, или
увеличивает счётчик на 1; у элемента корзины можно увеличивать количество и
удалять его; под корзиной выводится полная сумма товаров.

## Реализация

Приложение на React находится в `src/main.jsx`. Список книг — константа `books`.
Состояние корзины хранится в `useState`, каждый элемент — книга с полем `count`.
Функции `addToCart`, `increase` и `removeItem` меняют состояние, интерфейс
перерисовывается автоматически. Общая сумма считается через `reduce` и выводится
под корзиной. Корзина сохраняется в `localStorage` и восстанавливается после
перезагрузки.

Стили находятся в `src/styles.css`, точка входа HTML — `index.html`.

## Запуск

В каталоге `lab5` выполнить `npm install`, затем `npm run dev` и открыть адрес,
который покажет Vite. Для сборки — `npm run build`.
