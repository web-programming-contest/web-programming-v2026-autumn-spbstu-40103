# Лабораторная работа 4

## Задание

Вариант 24. Нужно сделать класс `User` с полями `id`, `name` и `friends`,
методами `addFriend` и `removeFriend` и геттером `friendCount`, который
возвращает количество друзей.

Также нужны функции для работы с массивом пользователей: сортировка по
количеству друзей, поиск пользователей без друзей, поиск самого популярного
пользователя, среднее количество друзей и группировка пользователей по
количеству друзей.

Интерфейс показывает пользователей карточками. Пользователя можно добавить через
форму и удалить кнопкой на карточке. Друзей можно добавлять и убирать.
Добавление и удаление выполняются асинхронно через `Promise` и `setTimeout`, а
данные сохраняются в `localStorage`.

## Реализация

Модель находится в `model.js`. Там лежит класс `User` и пять функций для работы
с массивом пользователей. Друзья хранятся как список `id` других пользователей.

Интерфейс находится в `main.js`. Он читает данные из `localStorage`, рисует
карточки и статистику, обрабатывает форму и кнопки. Каждое изменение (добавление
или удаление пользователя, добавление или удаление друга) выполняется через
`setTimeout`, потом данные сохраняются в `localStorage` и страница
перерисовывается без перезагрузки.

Разметка находится в `index.html`, стили в `styles.css`.

## Запуск

Модули ES не работают при открытии файла напрямую, поэтому страницу нужно
открывать через локальный сервер. В каталоге `lab4` можно выполнить
`python -m http.server 8000` и открыть `http://localhost:8000`. Также подойдёт
расширение Live Server в VS Code.
