# Лабораторная работа 1

## Задание

Создать регистрационную форму с полями: имя, фамилия, email, пароль,
подтверждение пароля, дата рождения, страна (выпадающий список), согласие с
условиями (checkbox) и кнопка отправки. Фон кнопки зелёный (#008000), цвет
текста белый. Отступы между полями 20px, фон формы белый, цвет текста чёрный. В
полях нужно корректно использовать атрибут type.

## Реализация

Разметка находится в index.html, оформление в styles.css. Каждое поле обёрнуто в
блок field с подписью label, связанной с полем через for и id. Используются типы
text, email, password и date, а также select и checkbox. Отступ 20px между
полями задан через gap у flex-контейнера формы. Стили вынесены в styles.css,
inline styles и ID-селекторы не используются.

## Запуск

Открыть файл index.html в браузере.
