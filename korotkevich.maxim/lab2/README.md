# Лабораторная работа 2

## Задание

4 вариант.

Написать функцию convertBase(num, fromBase, toBase), преобразующую число между
системами счисления

## Реализация

Решение состоит из одного файла solution.js с экспортируемой функцией
convertBase parseInt(num, fromBase) - переводит входное значение в десятичное
число decNumber.toString(toBase) — переводит десятичное число в строку целевой
системы счисления Проверка Number.isSafeInteger() нужна для защиты от потери
точности на больших числах. При превышении диапазона выбрасывается RangeError

## Запуск

Импортируйте именованный export из solution.js как ES module.
