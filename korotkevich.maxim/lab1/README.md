# Лабораторная работа 1

## Задание

4 вариант.

Создать таблицу с данными о продажах за месяц. Таблица должна иметь три
столбца - "Продукт", "Продано", "Выручка" и пять рядов с данными. В футере
таблицы необходимо отобразить общую сумму проданных товаров и общую выручку. При
создании таблицы необходимо использовать соответствующие семантические теги -
<thead>, <tbody>, <tfoot> и другие. Фон у четных строк должен быть светло-серым
(#f2f2f2), а у нечетных — белым (#ffffff). Ряд таблицы при наведении курсора
должен выделяться более темным серым цветом (#d3d3d3).

## Реализация

Создана HTML-страница с семантической таблицей (использованы теги `<thead>`,
`<tbody>`, `<tfoot>`). С помощью CSS добавлены отступы, границы и чередование
цветов фона для четных и нечетных строк. Реализовано выделение строки при
наведении курсора (hover)

## Запуск

Откройте `index.html` в браузере.
