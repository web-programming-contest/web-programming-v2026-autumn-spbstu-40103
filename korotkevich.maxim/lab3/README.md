# Лабораторная работа 3

## Задание

4 вариант.

Реализовать функцию `mergeArrays(arr1, arr2)`, которая объединяет два массива,
удаляя дубликаты.

## Реализация

Решение состоит из одного файла `solution.js` с экспортируемой функцией
`mergeArrays`.

С помощью оператора `[...arr1, ...arr2]` оба массива объединяются в один.
Исходные массивы при этом не изменяются.Полученный массив передаётся в
конструктор `new Set()`. Объект `Set` автоматически удаляет все дубликаты. С
помощью оператора `[...]` объект `Set` преобразуется обратно в массив, который
возвращается из функции.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
