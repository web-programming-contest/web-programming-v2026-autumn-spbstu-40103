# Лабораторная работа 5

## Задание

Вариант 36. Модальное окно в магазине книг.

Создать список книг, который будет содержать обложку книги и название.
Реализовать компонент модального окна для книги (информация о книге, на которую
кликнули). Функциональность:

- открытие модального окна при клике на карточку книги;
- закрытие: по кнопке (X), по клику вне области модального окна, по нажатию
  клавиши Esc.

Библиотеки компонентов и UI-фреймворки, кроме React, не используются.

## Реализация

Приложение написано на React (JSX) и собирается Vite.

### Данные (`src/books.js`)

Статичный каталог из 6 книг. Все изображения обложек находятся в локальной
директории `src/assets/` и импортируются напрямую в код, что обеспечивает
автономность работы приложения без доступа к внешним сетям и CDN.

### Компоненты

- `App.jsx` — корневой компонент приложения, хранит выбранную книгу в состоянии
  (`useState`), рендерит сетку карточек и модальное окно.
- `BookCard.jsx` — карточка книги (`data-testid="book-card"`), клик по карточке
  вызывает `onSelect(book)`.
- `BookModal.jsx` — модальное окно (`data-testid="book-modal"`). Находится в DOM
  постоянно с переключением видимости через CSS-класс `.modal-overlay-open` для
  обеспечения стабильности публичного контракта автотестов.

### Пользовательские сценарии

1. _Просмотр каталога_: пользователь видит список книг с обложками и названиями.
2. _Просмотр информации о книге_: при клике на карточку книги открывается
   модальное окно с детальной информацией (автор, год, жанр, описание, цена).
3. _Закрытие модального окна_: окно закрывается тремя способами:

- клик по кнопке `X` (`data-testid="modal-close"`);
- клик по затемнённой области вне диалога;
- нажатие клавиши `Escape`.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
