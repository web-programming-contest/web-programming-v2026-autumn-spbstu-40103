# Gadget Hub

**Интернет-магазин гаджетов: React + Spring Boot**


---

## Возможности

- **Главная** — баннер, закольцованные карусели «Хиты продаж» и «Новинки», блок
  преимуществ, контакты.
- **Авторизация** — сессионная (cookie `JSESSIONID`), валидация формы, ошибка
  входа во всплывающем окне, редирект неавторизованных на `/login`.
- **Каталог** — сетка по 3 карточки, сортировка (новизна / популярность / цена;
  повторный клик по критерию меняет направление), фильтры (цена, тип, цвет),
  пагинация, модальное окно товара (закрытие по ×, Esc, клику вне окна).
- **Корзина** — хранится в `localStorage` отдельно для каждого пользователя,
  массовое удаление с подтверждением, форма оформления заказа с валидацией,
  очистка корзины после заказа.
- **История заказов** — номер, дата, количество товаров, сумма.
- **Backend** — REST API, данные в JSON-файлах, асинхронное чтение и запись
  (`CompletableFuture`), атомарная запись через временный файл.

## Быстрый старт

Нужно: **JDK 21**, **Maven 3.9+**, **Node.js 18+**. Фронтенд и бэкенд
запускаются одновременно, в двух терминалах.

```bash
# Терминал 1 — бэкенд, http://localhost:8080
cd backend
mvn spring-boot:run
```

```bash
# Терминал 2 — фронтенд, http://localhost:3000
cd frontend
npm install
npm run dev
```

Откройте <http://localhost:3000>.

**Тестовый пользователь:** логин `user`, пароль `password123`.

При первом запуске бэкенд копирует начальные данные из
`src/main/resources/data/` в `backend/data/`. Это рабочее хранилище (оно в
`.gitignore`). Чтобы сбросить заказы или подхватить изменения в начальных
данных, остановите бэкенд и удалите папку `backend/data/`.

## REST API

| Метод | Путь      | Доступ    | Описание                                                                                                                                                   |
| ----- | --------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST  | `/login`  | все       | Вход, создаёт сессию                                                                                                                                       |
| POST  | `/logout` | все       | Завершает сессию                                                                                                                                           |
| GET   | `/me`     | все       | Текущий пользователь (401, если не вошёл)                                                                                                                  |
| GET   | `/goods`  | все       | Товары: `priceFrom`, `priceTo`, `category`, `color` (через запятую), `sort` = `newest` / `popular` / `price`, `order` = `asc` / `desc`, `page`, `pageSize` |
| GET   | `/orders` | 🔒 сессия | История заказов пользователя                                                                                                                               |
| POST  | `/orders` | 🔒 сессия | Создать заказ                                                                                                                                              |

`/goods` открыт намеренно: товары нужны на главной незалогиненному пользователю.
Доступ к странице каталога ограничен на фронтенде.

Цена и название товара в заказе берутся на сервере из каталога, клиент присылает
только `productId` и `quantity`.

<details>
<summary>Примеры запросов (curl)</summary>

```bash
curl -c cookies.txt -X POST http://localhost:8080/login \
  -H "Content-Type: application/json" \
  -d '{"username":"user","password":"password123"}'

curl "http://localhost:8080/goods?category=Смартфоны&sort=price&order=asc&page=1"

curl -b cookies.txt -X POST http://localhost:8080/orders \
  -H "Content-Type: application/json" \
  -d '{"items":[{"productId":6,"quantity":1}],"phone":"+79991234567","deliveryType":"pickup","paymentMethod":"cash","needsPackaging":false}'

curl -b cookies.txt http://localhost:8080/orders
```

</details>

## Проверка по критериям приёмки

1. Главная: хиты и новинки.
2. `/login` с пустыми или неверными данными: подсветка полей и всплывающее окно
   с ошибкой.
3. Вход как `user` / `password123`.
4. Каталог → сортировка (повторный клик по критерию меняет направление).
5. Фильтры → «Показать» → добавление товаров в корзину.
6. Корзина → форма оформления → «Оформить заказ».
7. Вкладка «История заказов»: заказ появился.
8. «Выйти»: каталог и корзина снова требуют входа.
9. Файл `backend/data/orders.json` содержит новый заказ.

## Если что-то не запускается

- **«Не удалось загрузить товары»**: бэкенд не запущен на `localhost:8080`.
- **Порт занят**: порт бэкенда задаётся в `application.properties`, порт
  фронтенда в `vite.config.js`. При смене порта бэкенда поправьте `API_BASE_URL`
  в `frontend/src/api/client.js`, а при смене порта фронтенда список адресов в
  `WebConfig.java` (CORS).
- **Не входит после перезапуска бэкенда**: сессия хранится в памяти сервера,
  войдите заново.
