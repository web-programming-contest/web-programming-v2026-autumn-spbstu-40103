# Gadget Hub — интернет-магазин гаджетов

Курсовой проект по дисциплине «Web-разработка». Веб-приложение из двух частей:
фронтенд (React + Vite) и бэкенд (Express), запускаются на разных локальных
портах и общаются через REST API.

## Структура проекта

```
gadget-hub/
├── backend/            # REST API на Express (порт 8080)
│   ├── server.js       # точка входа, эндпоинты
│   └── data/           # данные в JSON-файлах
│       ├── goods.json  # товары (32 позиции)
│       ├── users.json  # пользователи
│       └── orders.json # заказы
└── frontend/           # React-приложение (порт 3000)
    ├── public/         # шрифты Rubik, изображения товаров, иконки
    └── src/
        ├── components/ # Header, Footer, ProductCard, Carousel, ProductModal,
        │               # Filters, Pagination, OrderForm, ConfirmDialog и др.
        ├── context/    # AuthContext (сессия), CartContext (корзина в localStorage)
        └── pages/      # MainPage, CatalogPage, CartPage, LoginPage
```

## Запуск

Требуется Node.js 20+.

### 1. Бэкенд (порт 8080)

```bash
cd backend
npm install
npm start
```

### 2. Фронтенд (порт 3000)

```bash
cd frontend
npm install
npm run dev
```

Открыть в браузере: http://localhost:3000

Запросы фронтенда к API проксируются dev-сервером Vite на `localhost:8080`,
поэтому CORS и куки сессии работают без дополнительной настройки.

## Backend API

| №   | Метод | Путь    | Назначение                                                         |
| --- | ----- | ------- | ------------------------------------------------------------------ |
| 1   | POST  | /login  | Проверяет логин/пароль, устанавливает сессию (cookie)              |
| 2   | POST  | /logout | Завершает активную сессию                                          |
| 3   | GET   | /me     | Возвращает текущего пользователя по сессии                         |
| 4   | GET   | /goods  | Возвращает массив товаров                                          |
| 5   | GET   | /orders | Возвращает заказы текущего пользователя (нужна сессия)             |
| 6   | POST  | /orders | Создаёт новый заказ, сохраняет в `data/orders.json` (нужна сессия) |

Данные хранятся в JSON-файлах, чтение/запись — асинхронные (`fs/promises`).

## Реализованный функционал

- **Авторизация**: форма логина с валидацией обязательных полей, всплывающее
  окно с ошибкой при неверной паре логин/пароль, сессия на cookie. Доступ к
  каталогу и корзине без входа закрыт редиректом на страницу логина.
- **Шапка**: логотип (ведёт на главную), ссылка на каталог, кнопка
  «Войти»/«Выйти», иконка корзины со счётчиком товаров, подсветка активного
  раздела.
- **Главная**: промо-баннер, закольцованные карусели «Хиты продаж» и «Новинки»
  со стрелками, блок преимуществ, контакты, подвал с соцсетями.
- **Каталог**: сетка по 3 карточки, сортировка (новые/популярные/подешевле/
  подороже), фильтры по цене (поля + двойной ползунок), типу и цвету, кнопки
  «Показать»/«Сбросить», сообщение «товары не найдены», пагинация вида «1 2 3 …
  N».
- **Карточка товара**: фото, название, цена, рейтинг, лейблы «Хит»/«Новинка»,
  кнопка «В корзину» либо степпер количества; по клику — модальное окно с
  описанием и характеристиками (закрытие по крестику и Esc).
- **Корзина**: хранение в localStorage (у каждого пользователя своя), вкладки
  «Корзина»/«История заказов», выбор товаров чекбоксами, удаление одного или
  выбранных товаров с подтверждением, итоговая сумма.
- **Оформление заказа**: телефон (обязательный), e-mail, самовывоз/доставка,
  адрес (обязателен при доставке), способ оплаты, упаковка; подсветка невалидных
  полей; после оформления корзина очищается, заказ уходит на бэкенд и появляется
  в истории заказов.
