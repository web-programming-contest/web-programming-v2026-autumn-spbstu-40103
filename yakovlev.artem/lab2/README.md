# Лабораторная работа 2

## Задание

Вариант 36. Реализовать функцию `reverseWords(str)`, которая переворачивает
каждое слово в строке, сохраняя порядок слов.

Пример: `"Hello world"` → `"olleH dlrow"`.

## Реализация

Решение находится в `solution.js` и экспортирует именованную функцию
`reverseWords`.

- Регулярное выражение `/\S+/gu` находит каждое слово — непрерывную
  последовательность непробельных символов.
- Каждое найденное слово разбивается на символы через `Array.from`,
  переворачивается и собирается обратно.
- Пробелы, табуляции и переводы строк не затрагиваются, поэтому количество
  пробелов между словами, а также ведущие и завершающие пробелы сохраняются.
- `Array.from` и флаг `u` корректно обрабатывают символы вне BMP, например
  эмодзи.
- Для пустой строки возвращается пустая строка.

## Запуск

Из каталога работы:

```bash
node -e "import('./solution.js').then(({ reverseWords }) => console.log(reverseWords('Hello world')))"
```
