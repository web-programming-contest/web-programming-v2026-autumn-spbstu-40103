# Лабораторная работа 4

## Задание

Вариант 36. Класс `User` и интерфейс для работы с пользователями.

1. Класс `User` с полями `id` (число), `name` (строка), `friends` (массив id
   друзей), методами `addFriend(friendId)`, `removeFriend(friendId)` и геттером
   `friendCount`.
2. Функции над массивом пользователей: группировка по количеству друзей,
   уникальный список всех друзей, пользователи с общим другом с заданным id,
   пользователи с количеством друзей больше заданного, пользователи без друзей.
3. Интерфейс: карточки пользователей (имя, ID, список друзей), кнопки «Добавить
   друга», «Удалить друга», «Добавить пользователя», «Удалить пользователя»,
   форма создания пользователя и форма добавления друга. Интерфейс обновляется
   автоматически, все операции добавления и удаления выполняются асинхронно
   через `Promise` и `setTimeout`, список сохраняется в `localStorage`.

## Реализация

Модель и интерфейс разделены.

`model.js` содержит класс `User` и функции работы с коллекцией:

- `groupUsersByFriendCount(users)` — `Map`, где ключ — количество друзей,
  значение — массив пользователей;
- `getUniqueFriends(users)` — массив уникальных id друзей;
- `findUsersWithFriend(users, friendId)` — пользователи, у которых в друзьях
  есть пользователь с id `friendId`;
- `findUsersAboveFriendCount(users, count)` — пользователи, у которых друзей
  больше `count`;
- `findUsersWithoutFriends(users)` — пользователи без друзей.

Функции не изменяют входной массив. `addFriend` не добавляет один и тот же id
дважды.

`main.js` отвечает за интерфейс:

- Каждая операция (`addUser`, `removeUser`, `addFriend`, `removeFriend`)
  выполняется через `runOperation`, которая оборачивает её в `Promise` и
  `setTimeout`.
- После успешной операции состояние сохраняется в `localStorage` (ключ
  `lab4-users`) и список перерисовывается. Дополнительно состояние сохраняется
  на событиях `pagehide` и `beforeunload`.
- Ошибки (повторный ID, пустое имя, друг не найден и т. д.) показываются в
  строке статуса.
- При удалении пользователя он также удаляется из списков друзей остальных.
- Данные пользователя выводятся через `textContent`, поэтому вставка HTML в имя
  безопасна.

Публичные `data-testid`: `entity-form`, `entity-list`, `entity-card`,
`delete-entity`. Поля формы: `id`, `name`; у формы друга поле `friendId`.
