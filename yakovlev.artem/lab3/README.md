# Лабораторная работа 3

## Задание

Вариант 36. Реализовать функцию `findMaxSubarraySum(arr, n)`, которая находит
максимальную сумму подмассива длины `n`.

## Реализация

Решение находится в `solution.js` и экспортирует именованную функцию
`findMaxSubarraySum`.

- Используется метод скользящего окна: сначала считается сумма первых `n`
  элементов, затем окно сдвигается на один элемент вправо — новый элемент
  прибавляется, вышедший из окна вычитается.
- Сложность — O(m) по времени и O(1) по памяти, где m — длина массива; перебор
  всех подмассивов дал бы O(m·n).
- Входной массив не изменяется.
- Если `n` не целое, не больше нуля или больше длины массива, функция возвращает
  `null`.
- Корректно работает для массивов из отрицательных чисел.

## Запуск

Из каталога работы:

```bash
node -e "import('./solution.js').then(({ findMaxSubarraySum }) => console.log(findMaxSubarraySum([1, 2, 5, 2, 8, 1, 5], 4)))"
```
