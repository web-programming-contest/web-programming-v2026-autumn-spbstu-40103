# Лабораторная работа 5

## Задание

Вариант 36. Реализовать модальное окно в магазине книг. Создать список книг с
обложкой и названием и компонент модального окна, который содержит информацию о
книге, на которую кликнули.

Функциональность:

- открытие модального окна при клике на карточку книги;
- закрытие по кнопке (×), по клику вне области модального окна и по нажатию
  клавиши Esc.

Использовать сторонние библиотеки для модального окна нельзя.

## Реализация

Приложение написано на React и собирается Vite.

- `src/data/books.js` — список из шести книг (название, автор, год, описание,
  обложка). Обложки лежат в `assets/` в виде SVG, поэтому приложению не нужен
  интернет.
- `src/App.jsx` — хранит в состоянии `selectedBook`. Компонент модального окна
  всегда находится в разметке и скрыт атрибутом `hidden`, пока `selectedBook`
  равен `null`.
- `src/components/BookCard.jsx` — карточка книги. Это `<button>`, поэтому её
  можно открыть с клавиатуры (Tab и Enter).
- `src/components/Modal.jsx` — модальное окно, написанное без библиотек:
  - по кнопке × вызывается `onClose`;
  - по клику вне окна: обработчик стоит на затемнённой подложке и закрывает
    окно, только если клик пришёл именно в неё
    (`event.target === event.currentTarget`), а клик внутри окна не закрывает
    его;
  - по Esc: в `useEffect` на `document` вешается обработчик `keydown`, который
    удаляется при закрытии окна;
  - при открытии фокус переходит на кнопку ×, при закрытии возвращается на
    карточку, с которой открыли окно;
  - пока окно открыто, прокрутка страницы заблокирована классом `modal-open` на
    `body`;
  - атрибуты `role="dialog"`, `aria-modal` и `aria-labelledby` нужны для
    доступности.

Публичные `data-testid`: `app`, `book-list`, `book-card`, `book-title`,
`book-modal`, `modal-overlay`, `modal-close`, `modal-title`, `modal-author`,
`modal-description`.

## Запуск

```bash
cd yakovlev.artem/lab5
npm install
npm run dev
```

Приложение откроется по адресу из вывода команды, обычно
`http://localhost:5173`. Сборка выполняется командой `npm run build`.
