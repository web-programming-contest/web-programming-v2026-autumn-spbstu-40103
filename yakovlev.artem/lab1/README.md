# Лабораторная работа 1

## Задание

Вариант 36. Создать таблицу с данными о продажах за месяц. Таблица имеет три
столбца: «Продукт», «Продано», «Выручка» и пять строк с данными. В футере
таблицы отображаются общее количество проданных товаров и общая выручка.
Используются семантические теги `<caption>`, `<thead>`, `<tbody>`, `<tfoot>`.
Фон чётных строк — светло-серый (`#f2f2f2`), нечётных — белый (`#ffffff`). При
наведении курсора строка выделяется более тёмным серым цветом (`#d3d3d3`).

## Реализация

Разметка находится в `index.html`, стили — в `styles.css`, inline-стили не
используются.

- Заголовок таблицы задан через `<caption>`, ячейки заголовков имеют атрибут
  `scope`.
- Цвета строк задаются псевдоклассами `tbody tr:nth-child(odd)` и
  `tbody tr:nth-child(even)`.
- Подсветка строки реализована через `tbody tr:hover`; правило стоит после
  правил чередования, поэтому перекрывает их.
- В `<tfoot>` выведены итоги: 112 проданных товаров и выручка 2 345 000 ₽.
- Таблица растягивается на ширину экрана, но не шире 600px, поэтому не вызывает
  горизонтальной прокрутки.

## Запуск

Открыть файл `index.html` в браузере.
