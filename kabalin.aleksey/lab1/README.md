# Лабораторная работа 1

## Задание

Вариант 26. Создать горизонтальное навигационное меню, где активный элемент
выделяется другим цветом. Для реализации можно использовать `<nav>`, `<ul>`,
`<li>`, и `<a>`. Один из пунктов меню должен быть активным (например, при помощи
class="active").

## Реализация

Сделано меню с помощью списка `<ul>`. Обёрнуто в `<nav>`. Также с помощью
`display: flex` меню переведено в горизонтальное положение. Активный элемент
выделен красным цветом и жиным шрифтом через класс `.active` через файл
`styles.css`.

## Запуск

Откройте `index.html` в браузере.
