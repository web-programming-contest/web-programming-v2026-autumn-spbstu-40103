# Лабораторная работа 2

## Задание

Вариант 26. Реализовать функцию analyzieString, которая на вход принимает строку
и возвращает следующий объект: • letters: количество букв • digits: количество
цифр • spaces: количество пробелов • other: остальные символы.

## Реализация

Реализована функция analyzieString, принимающая на вход строку. Производится
проход по всем символам строки и проверяется отношение к типам (letters: по
Unicode `/\p{L}/u.test(char)`, digits: `/[0-9]/.test(char)`, spaces:
`char === ' '`, other: всё, что не прошло предыдущие проверки). Функция
возращает объект, хранящий информацию о строке в таком формате:
`{letters, digits, spaces, other}`.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
