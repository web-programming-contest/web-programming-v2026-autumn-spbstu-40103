# Лабораторная работа 5

## Задание

Задача 5. Реализовать модальное окно в магазине книг. Список книг с обложкой и
названием; компонент модального окна с информацией о книге, на которую кликнули.
Открытие по клику на карточку книги; закрытие по кнопке (X), по клику вне
области модального окна и по нажатию Esc. Библиотеки использовать нельзя.

## Реализация

React + Vite. `App` хранит выбранную книгу в состоянии, `BookCard` — карточка
(кнопка с обложкой и названием), `BookModal` — модальное окно. Модальное окно
всегда находится в DOM и скрывается атрибутом `hidden`. Закрытие: кнопка ×, клик
по затемнённому фону (`event.target === event.currentTarget`), клавиша Esc
(слушатель на `document`, снимается в cleanup у `useEffect`). Обложки лежат в
`assets/` (jpg) и импортируются в `src/data/books.js`, внешних ресурсов нет.

## Запуск

    cd bogdanova.larisa/lab5
