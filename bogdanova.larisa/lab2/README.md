# Лабораторная работа 2

## Задание

Вариант 19. Написать функцию generateParentheses(n), которая генерирует все
возможные правильные комбинации скобок для n пар. Например, для n = 2 результат:
["(())", "()()"].

## Реализация

Решение находится в файле solution.js. Функция generateParentheses(n)
экспортируется как именованный экспорт и возвращает массив строк.

Внутри используется рекурсивная вспомогательная функция build, которая строит
строку по одной скобке:

1. Когда длина строки достигает 2n, строка добавляется в результат;
2. Открывающую скобку можно добавить, пока их использовано меньше n;
3. Закрывающую скобку можно добавить, только если закрытых скобок меньше, чем
   открытых. Благодаря этому все получаемые строки правильные.

## Запуск

Файл solution.js является ES-модулем. Функцию можно импортировать в другом
модуле командой import { generateParentheses } from './solution.js' и вызвать,
например, generateParentheses(2).
