# Лабораторная работа 4

## Задание

Вариант 19. Задача «Товары и поставщики».

4.1. Создать класс `Product` с полями:

- `id` — номер (число);
- `name` — название (строка);
- `suppliers` — массив имён поставщиков (строки).

Реализовать методы:

- `addSupplier(name)` — добавить поставщика;
- `removeSupplier(name)` — удалить поставщика;
- геттер `supplierCount` — количество поставщиков.

4.2. Дан массив товаров. Реализовать функции:

- группировка товаров по поставщикам (поставщик → массив товаров);
- уникальный список всех поставщиков;
- товары с заданным поставщиком;
- группировка товаров по количеству поставщиков;
- товары с максимальным числом поставщиков.

4.3. Пользовательский интерфейс:

- список карточек товаров (название, список поставщиков, количество
  поставщиков);
- кнопки «Добавить поставщика», «Удалить поставщика», «Добавить товар», «Удалить
  товар»;
- форма создания товара и форма добавления поставщика;
- автоматическое обновление интерфейса при любых изменениях;
- все операции добавления/удаления — асинхронно через `Promise + setTimeout()`;
- сохранение текущего списка товаров в `localStorage`.

## Реализация

Приложение написано на HTML, CSS и JavaScript без сторонних библиотек.

- `index.html` — форма создания товара (номер, название, поставщики через
  запятую), блок сообщений об ошибках, контейнер списка карточек и блок
  «Аналитика».
- `model.js` — класс `Product` и пять функций работы с коллекцией:
  `groupProductsBySupplier`, `getUniqueSuppliers`, `findProductsBySupplier`,
  `groupProductsBySupplierCount`, `findProductsWithMostSuppliers`.
- `main.js` — асинхронные функции `addProduct`, `deleteProduct` и
  `changeSupplier`, обработчики событий, создание карточек, сохранение и
  загрузка данных.
- `styles.css` — оформление формы, кнопок и карточек. Список карточек построен
  на CSS Grid с автоматическим переносом строк.

Класс `Product` хранит `id`, `name` и собственную копию массива `suppliers`:
конструктор добавляет поставщиков по одному через `addSupplier`, поэтому
переданный массив не изменяется. Метод `addSupplier` обрезает пробелы и
добавляет имя, только если оно непустое и ещё не встречается в списке,
`removeSupplier` удаляет поставщика по имени. Оба метода возвращают `true` или
`false` в зависимости от того, изменился ли список. Геттер `supplierCount`
возвращает длину массива `suppliers`. Функции работы с коллекцией не изменяют
исходный массив; группировка по поставщикам возвращает объект, группировка по
количеству поставщиков возвращает Map (ключ — количество поставщиков), а пустая
коллекция в `findProductsWithMostSuppliers` даёт пустой массив.

При добавлении товара проверяются непустое название, числовой номер и отсутствие
товара с таким же номером. Если номер не указан, он назначается автоматически
(максимальный существующий плюс один). Добавление выполняется по событию
`submit` формы. Каждая карточка показывает название и номер товара, список
поставщиков, их количество, собственную форму поставщиков (поле ввода и кнопки
«Добавить поставщика» и «Удалить поставщика») и кнопку «Удалить товар». Кнопки
удаления и формы поставщиков обрабатываются делегированием событий на контейнере
списка.

Все операции изменения состояния ждут `delay(300)`, то есть
`new Promise((resolve) => setTimeout(resolve, 300))`, и только после этого
изменяют массив товаров. Затем вызывается `commit()`: он сохраняет данные в
`localStorage` и перерисовывает карточки и блок «Аналитика». Весь
пользовательский текст выводится через `textContent`, чтобы введённые данные не
интерпретировались как HTML.

Список хранится в `localStorage` под ключом `lab4-products` в формате JSON. При
загрузке страницы функция `load` превращает сохранённые объекты обратно в
экземпляры `Product` (иначе пропал бы геттер `supplierCount`), а при
повреждённых данных возвращает пустой список.

Для автопроверки используются атрибуты `data-testid`: `entity-form` у формы,
`entity-list` у списка, `entity-card` у карточек и `delete-entity` у кнопок
удаления внутри карточек.

## Запуск

Файлы подключаются как ES-модули, поэтому `index.html` нужно открывать через
локальный сервер (например, расширение Live Server в VS Code или команда
`npx serve` в папке `lab4`). Открытие файла напрямую (`file://`) не работает.
