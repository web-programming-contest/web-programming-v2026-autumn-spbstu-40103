# Лабораторная работа 1

## Задание

Вариант 19. Создать сетку из изображений, которая будет адаптивно подстраиваться
под размер экрана. На больших экранах должно быть больше колонок, чем на
маленьких.

## Реализация

Страница содержит заголовок `<h1>` и блок `.gallery` с восемью изображениями,
обернутые в `<main>`:

1. Фотографии лежат в папке assets и подключены на страницу в index.html;
2. Они выстроены сеткой: на узких экранах в одну колонку, на более широких в
   две, три или четыре колонки;
3. Все оформление (отступы, скругленные углы, размеры картинок) находится в
   файле styles.css;
4. Изображения одинаковой высоты и не растягиваются: лишнее обрезается.

## Запуск

Открыть файл index.html в браузере.
