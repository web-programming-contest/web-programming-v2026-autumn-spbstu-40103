# Лабораторная работа 3

## Задание

Вариант 19. Реализовать функцию sortArrayByParity(arr), которая сортирует массив
так, чтобы чётные числа шли перед нечётными. Порядок внутри групп не важен.

## Реализация

Решение находится в файле solution.js. Функция sortArrayByParity(arr)
экспортируется как именованный экспорт и возвращает новый массив, исходный
массив не изменяется.

1. Числа из массива раскладываются в два списка: чётные и нечётные (проверка
   через остаток от деления на 2);
2. Внутри каждого списка числа дополнительно упорядочиваются по возрастанию;
3. Результатом является список чётных, за которым идёт список нечётных.

## Запуск

Файл solution.js является ES-модулем. Функцию можно импортировать в другом
модуле командой import { sortArrayByParity } from './solution.js' и вызвать,
например, sortArrayByParity([3, 1, 2, 4]).
