# Gadget Hub — курсовой проект

Интернет-магазин гаджетов. Фронтенд (Vanilla JS + Vite) и бэкенд (REST API на Node.js) запускаются на разных локальных серверах.

## Возможности

- главная: две закольцованные карусели (хиты и новинки), преимущества, контакты;
- каталог: фильтры по цене, типу и цвету, сортировка по цене, популярности и новизне, пагинация по 9 товаров, карточка товара в модальном окне;
- авторизация: серверная сессия в HttpOnly cookie, защита каталога, корзины и заказов;
- корзина в `localStorage`: счётчик в шапке, выбор товаров, подтверждение удаления;
- оформление заказа: проверка полей в браузере и на сервере, самовывоз или доставка, оплата, упаковка;
- история заказов хранится в JSON-файле, запись выполняется асинхронно через `fs/promises`.

## Запуск

Нужен Node.js 20 или новее. Из папки проекта:

```bash
npm install
npm start
```

`npm start` запускает оба сервера:

- фронтенд: http://localhost:3000;
- API: http://localhost:8080.

Остановка: `Ctrl+C`.

Отдельные команды: `npm run frontend` (только фронтенд), `npm run backend` (только API), `npm run build` (сборка фронтенда в `frontend/dist`).

## Демо-пользователь

- логин: `student`
- пароль: `gadget123`

## API

- `POST /login`: вход, тело `{ "login": "student", "password": "gadget123" }`
- `POST /logout`: выход
- `GET /session`: состояние входа
- `GET /goods`: список товаров (публичный)
- `GET /orders`: история заказов, нужна сессия
- `POST /orders`: создание заказа, нужна сессия

Пример тела заказа:

```json
{
  "items": [{ "id": 1, "quantity": 2 }],
  "phone": "+7 999 123-45-67",
  "email": "student@example.com",
  "delivery": "pickup",
  "address": "",
  "payment": "card",
  "packaging": true
}
```

`delivery`: `pickup` или `delivery` (при доставке адрес обязателен), `payment`: `card` или `cash`. Цены сервер берёт из каталога сам.

## Структура

- `frontend/`: интерфейс (`index.html`, `app.js`, `style.css`), конфиг Vite, `assets/` с картинками, иконками и шрифтом Rubik;
- `backend/`: API (`server.js`) и JSON-хранилище (`data/goods.json`, `data/orders.json`);
- `start.js`: запуск бэкенда и Vite одной командой.

## Допущения

- Проект учебный: сессии хранятся в памяти и сбрасываются при перезапуске сервера, реальной оплаты нет.
- Цены, рейтинги, типы и цвета товаров дополнены демонстрационными данными.
- Социальные ссылки ведут на главные страницы сервисов.
- Чтобы очистить историю заказов, остановите сервер и замените `backend/data/orders.json` на `[]`.
- Лицензия шрифта Rubik: `frontend/assets/OFL.txt`.

## Проверка

Ручной сценарий: главная -> неверный логин -> вход -> каталог -> сортировка и фильтры -> добавление в корзину -> оформление заказа -> история заказов -> выход.
