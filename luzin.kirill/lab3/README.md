# Лабораторная работа 3

## Задание

Вариант 16.

Реализуйте функцию findEquilibriumIndex(arr), которая находит индекс, где сумма
левой и правой части массива равна.

## Реализация

В начале программы вычисляются базовые суммы слева(sumL) и справа(sumR). Далее в
цикле, начиная с индекса 0:

1. Из sumR вычитается значение по текущему индексу
2. Если суммы равны, возвращается текущий индекс
3. В sumL добавляется значение по текущему индексу

Если подходящий индекс не найден, возвращается -1.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
