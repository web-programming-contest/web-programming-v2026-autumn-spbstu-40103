# Лабораторная работа 2

## Задание

Вариант 16.

Реализовать функцию, которая проверяет, является ли строка изограммой (не имеет
повторяющихся букв, игнорируя регистр).

## Реализация

Строка приводится к нижнему регистру. В цикле каждая буква добавляется в
множество set, но если такая буква уже встречалась, то возвращается false. Если
ни одна буква не повторилась, то возвращается true.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
