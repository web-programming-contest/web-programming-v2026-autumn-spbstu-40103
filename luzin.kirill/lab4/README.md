# Лабораторная работа 4

## Задание

Вариант 16.

4.1. Создать класс restaurant с полями: • name — название ресторана (строка) •
menu — массив блюд, каждое с полями: name и price Реализовать методы: •
addDish(dish) — добавить блюдо • removeDish(dishName) — удалить блюдо по имени •
геттер menuSize — количество блюд

4.2. Дан массив ресторанов: • Группировать рестораны по количеству блюд •
Получить уникальный список всех блюд • Вернуть рестораны, в меню которых есть
заданное блюдо • Группировать блюда по ценовым диапазонам • Получить рестораны с
самым дорогим блюдом

4.3. Реализовать пользовательский интерфейс: • Карточки ресторанов: название,
меню (блюда и цены), количество позиций в меню • Кнопки: "Добавить блюдо",
“Удалить блюдо”, “Добавить ресторан”, "Удалить ресторан"  
• Форма создания ресторана. Форма добавления блюда • При любых изменениях
автоматически обновлять пользовательский интерфейс • Все операции
добавления/удаления выполнять асинхронно через Promise + setTimeout() •
Использовать local storage для сохранения текущего списка студентов при закрытии
вкладки.

## Реализация

Модель основана на классе Restaurant, который описывает ресторан (название,
меню) и содержит методы управления блюдами (addDish, removeDish, геттер
menuSize).

Функции коллекции: Реализовано пять функций для аналитики массива: поиск по
конкретному блюду, группировка по количеству блюд, по диапазону цен, поиск
уникальных блюд и заведений с самой дорогой позицией.

Логика интерфейса: данные изменяются при удалении или добавлении элементов через
формы, после чего карточки полностью перерисовываются. Весь список ресторанов
автоматически сохраняется в localStorage и выгружается оттуда с помощью JSON.

## Запуск

Откройте `index.html` в браузере или запустить локально сервер.
