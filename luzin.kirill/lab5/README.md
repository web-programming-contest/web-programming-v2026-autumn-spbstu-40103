# Лабораторная работа 5

## Задание

Вариант 16.

Создать приложение прогноза погоды 49 Приложение будет отображать текущую погоду
и прогноз на несколько дней вперед с использованием открытого API погодных
данных. Функциональность: - текущая погода с основными показателями; -
возможность сменить город; - возможность менять интервал просмотра погоды (1
день, 3 дня, 7 дней) – опционально.

## Реализация

Интерактивное React-приложение. Получение геоданных и прогноза погоды из
открытого API Open-Meteo с помощью fetch запросов. Логика приложенние построена
на useState для хранения текущего города и интервала прогноза и useEffect для
автоматической загрузки данных при изменении этих параметров. В src/main.jsx
основная логика получения информации через API и создания html разметки. В
src/wmo.js находится расшифровка кодов WMO для отображения корректного
отображения прогноза погоды.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
