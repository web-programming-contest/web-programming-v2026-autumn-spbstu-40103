# Gadget Hub — frontend

Frontend курсового проекта на ванильном JavaScript. Реализованы четыре страницы из макета: главная, логин, каталог и корзина/история заказов.

## Запуск

Сначала запустите backend на `http://localhost:8080`, затем здесь:

```bash
npm install
npm start
```

Откройте **http://localhost:3000** (важно использовать `localhost`, а не случайный другой порт).

Демо-пользователь backend:

- логин: `student`
- пароль: `12345`

## Реализовано

- общие header/footer и локальный шрифт Rubik;
- публичная главная с закольцованными каруселями хитов и новинок;
- авторизация с валидацией полей и серверной сессией;
- защита каталога и корзины редиректом на логин;
- каталог: 3 карточки в ряд, сортировка, фильтры цены/типа/цвета, сброс, пагинация;
- карточка товара в модальном окне, закрытие крестиком, кликом по фону и Esc;
- корзина в `localStorage`, изменение количества и счетчик в header;
- одиночное и групповое удаление с подтверждением;
- форма заказа с валидацией, доставкой/самовывозом, оплатой и упаковкой;
- отправка заказа на backend, очистка `localStorage`, сообщение об успехе;
- история заказов с backend.

## Дизайн

Верстка рассчитана на desktop, как требует задание. Контент имеет фиксированную ширину и центрируется. Стили ориентированы на приложенные Gadget Hub pages/UI kit и экспорт из Figma. Баннер главной, иконки преимуществ и контактов взяты из `figma-export.zip`; картинки товаров, навигационные иконки, соцсети и Rubik — из предоставленного архива Assets.

Исходный `goods.json` из Assets содержит только id/названия и имеет синтаксическую ошибку в названии товара №28. Поэтому для рабочего проекта frontend использует расширенные данные товаров, которые отдаёт backend: к исходным названиям/изображениям добавлены необходимые для требований цена, категория, цвет, рейтинг, признаки «Новинка/Хит», описание и характеристики.
