# Лабораторная работа 1

## Задание

Вариант 31. Создать каталог товаров, сгруппированных по категориям. Категории и
товары должны быть представлены в виде списков. Внутри каждой категории должен
находиться список относящихся к ней товаров. Каждый товар должен содержать
название, выделенное жирным шрифтом, краткое описание и цену, выделенную
курсивом.

## Реализация

Страница реализована на HTML и CSS без JavaScript. Каталог построен как
вложенные неупорядоченные списки: внешний список содержит категории, внутренние
списки — товары. Название товара оформлено тегом `strong`, цена — тегом `em`.
Стили подключены отдельным файлом `styles.css`; inline-стили не используются.
Добавлено адаптивное состояние для узких экранов, горизонтальный overflow
отсутствует.

## Запуск

Откройте `index.html` в браузере.
