# Лабораторная работа 3

## Задание

Вариант 31. Реализовать функцию `intersection(arr1, arr2)`, которая возвращает
массив общих элементов двух входных массивов.

## Реализация

Функция `intersection` экспортируется как именованный ES module export. Для
быстрого поиска элементов второго массива используется `Set`. Результат также
формируется через `Set`, чтобы одинаковый общий элемент не добавлялся несколько
раз. После обхода первого массива множество преобразуется обратно в обычный
массив.
