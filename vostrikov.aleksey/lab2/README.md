# Лабораторная работа 2

## Задание

Вариант 31. Реализовать функцию `isPerfectNumber`, которая проверяет, является
ли положительное целое число совершенным. Совершенным считается число, равное
сумме своих положительных делителей, не включая само число. Число 1 совершенным
не является.

## Реализация

Функция `isPerfectNumber` экспортируется как именованный ES module export. Для
проверки делителей перебор выполняется до квадратного корня из числа. Если
найден делитель, к сумме добавляется как он сам, так и парный делитель. Для
полного квадрата парный делитель повторно не добавляется. Для числа 1
возвращается `false`.

npm run format -- vostrikov.aleksey/lab2
