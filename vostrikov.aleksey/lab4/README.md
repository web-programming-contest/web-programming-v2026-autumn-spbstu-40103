# Лабораторная работа 4

## Задание

Вариант 31. Создать класс `Recipe` с полями `title`, `ingredients` и `steps`,
методами добавления и удаления ингредиентов и геттером `ingredientCount`. Для
массива рецептов реализовать группировку по количеству ингредиентов, получение
уникальных ингредиентов, поиск рецептов по ингредиенту, группировку по
количеству шагов и получение списка названий рецептов.

Также реализовать пользовательский интерфейс с карточками рецептов, формой
добавления, операциями добавления и удаления ингредиентов и шагов, асинхронным
добавлением и удалением и сохранением данных в `localStorage`.

## Реализация

Модель вынесена в `model.js`. Класс `Recipe` и пять функций для работы с
коллекцией экспортируются именованно. Интерфейс реализован в `main.js`.
Добавление и удаление выполняются через `setTimeout`, после изменений DOM
перерисовывается, а текущее состояние сохраняется в `localStorage`.

Для браузерного контракта используются `data-testid="entity-list"`,
`data-testid="entity-form"`, `data-testid="entity-card"` и
`data-testid="delete-entity"`.
